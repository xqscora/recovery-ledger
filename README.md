# Recovery Ledger

Recovery Ledger is a local-first planning prototype for NextStep Hacks 2026's Earth Forward theme. It makes a missed commitment inspectable: the user can mark a task recoverable, change available time, and see the smallest feasible next action while the original effort and dependency stay visible.

## Run

Open `index.html` in a browser. No build step or server is required.

## Boundaries

- Demo data is synthetic and stays in the browser.
- The app does not diagnose stress, assign personality labels, or generate a wellness score.
- The recovery suggestion is a transparent rule, not a claim about the user's mental state.

## Built with

HTML5, CSS3, vanilla JavaScript, browser DOM APIs, and the Web Crypto UUID helper.

## AI-use disclosure

AI coding assistance was used for brainstorming, implementation drafting, and debugging. The project owner reviewed the code and remains responsible for understanding and explaining the interaction model and all final decisions.
